
# Reena Mehta College – Academic Performance Analytics

## Project Overview
This project analyzes student academic performance at Reena Mehta College using Python and Tableau. Python, Pandas, and NumPy were used to clean and prepare the dataset. The cleaned dataset was then loaded into Tableau to create an interactive dashboard with KPIs, filters, and visualizations.

## Project Objectives
- Analyze overall student academic performance.
- Evaluate student pass and failure percentages.
- Compare academic performance across departments and semesters.
- Identify top-performing students.
- Analyze student attendance percentage.
- Present insights through an interactive Tableau dashboard.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Tableau Desktop
- Microsoft Excel

## Data Cleaning & Preparation
- Imported the raw academic dataset using Python.
- Performed data cleaning and preprocessing using Pandas and NumPy.
- Prepared the cleaned dataset for Tableau visualization.
- Final cleaned dataset contains 1,006 records.

## Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Students | 1,006 |
| Pass Percentage | 87.77% |
| Total Passed Students | 879 |
| Average Marks | 65.55 |
| Total Failed Students | 123 |
| Average Attendance Percentage | 84.04% |

## Dashboard Analysis
The Tableau dashboard includes:

- Grade-wise Student Distribution
- Semester-wise Average Marks
- Top 5 Students
- Department-wise Average Marks
- Department-wise Pass Percentage
- Interactive Filters for Department, Course, Gender, and Semester

## Key Insights
- A total of 1,006 students are included in the analysis.
- The overall pass percentage is 87.77%.
- A total of 879 students passed, while 123 students failed.
- The average student mark is 65.55.
- The average attendance percentage is 84.04%.
- Department-wise and semester-wise visualizations help compare academic performance.
